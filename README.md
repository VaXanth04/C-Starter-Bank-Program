Made my first project using C. It is nothing complicating at all. Just a small and simple program for a "Bank Menu".It allows the user to log in via a 4 digit PIN, check his balance, deposit money and of course withdraw too. The user only has 3 tries to submit the correct PIN (9691) or else the program gets terminated. The code also contains some "fake" UI modifications via *printf* command that I was experimenting. It was also the first time for me to use a different library besides: stdio.h & stdlib.h: windows.h . Enjoy!
